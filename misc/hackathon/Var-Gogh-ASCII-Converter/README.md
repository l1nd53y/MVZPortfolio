### What I learned

I experienced what it's like to develop an MVP over two days time, and the importance of setting realistic goals in approaching a time-sensitive goal. Using VSCode's "Live Share" extension was also a completely new experience.


### Setup:
```
- Clone project
$ cd ../project_name
$ npm install
- Add or select image you'd like to convert in client/public/images folder
- Modify filepath in convert.js to desired image
$ node convert.js

Should then see converted ASCII "image" output in terminal.

```
