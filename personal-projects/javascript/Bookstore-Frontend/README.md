# Introduction | Bookstore Ecommerce App (Frontend)

An ecommerce bookstore application. Frontend setup provides UI for allowing a user to CRUD books and genres, view bookstore inventory by genre, create users, create wishlists, add to cart, and place orders.

## Overview

### Objectives:

Users should be able to:

- [x] Access an inventory of books
- [x] Add a book to an order
- [x] Check out an order
- [x] Sign in and out of bookstore account
- [x] Sign up for an account
- [x] Create a wishlist

Stretch goals (to-do):

- [ ] See a previous order
- [ ] Make search bar functional
- [ ] Make 'Admin' functionality only accessible to specific signed in users
- [ ] Empty cart after checkout
- [ ] Improve appearance of UI
- [ ] Deploy frontend
