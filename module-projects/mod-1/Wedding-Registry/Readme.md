# Introduction | TieMyKnot Wedding Registry App

The application will allow couples to post registry gift requests and view the purchase status of registry gifts. It will also allow all guests to view the purchase status of gifts, reserve gifts they intend to purchase, update the purchase status of the gift they reserved.

## Overview

### Objectives:

Users should be able to:

- [x] Post registry gift requests
- [x] Add items to the registry by filling out a form
- [x] Allow guests to view a registry
- [x] Allow guests to "reserve" item(s) from registry
- [x] Observe application's responsiveness and that A11Y criteria is met


Stretch goals (to-do):
